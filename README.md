RSVP Movies Global Release Analytics
This project analyzes movie data from RSVP Movies, an Indian film production company known for producing hit films. The company is planning to release its first movie for a global audience in 2022. The goal is to use past movie data (from the last three years) to derive insights that will help guide their decisions for the new project.

Project Overview
RSVP Movies aims to make data-driven decisions to plan their global release. Using SQL, we have analyzed the movie data provided to uncover key insights related to:

Popular genres
Optimal movie duration
Successful collaborators
Audience preferences
